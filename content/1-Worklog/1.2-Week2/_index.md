### Results achieved in Week 2:

- Understood the role of Amazon S3 in data storage on AWS.

- Acquired the ability to perform core S3 operations:
  - Create Buckets.
  - Upload and manage Objects.
  - Understand Key structure in S3.
  - Verify resource access permissions.

- Mastered the operating principles of AWS Lambda:
  - Lambda Function.
  - Runtime.
  - Event-driven execution.
  - Triggers from other AWS services.

- Understood how to utilize Amazon DynamoDB:
  - NoSQL data organization.
  - Partition Key and Sort Key.
  - Item-based data storage.

- Defined the appropriate AWS service architecture for the system:
  - Amazon S3 used for storing input and output images.
  - AWS Lambda responsible for image optimization processing.
  - Amazon DynamoDB stores metadata and processing status.

- Established foundational knowledge to begin designing and deploying the **Automatic Image Optimization System on AWS**.
